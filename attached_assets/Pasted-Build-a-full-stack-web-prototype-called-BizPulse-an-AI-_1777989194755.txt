Build a full-stack web prototype called **BizPulse** — an AI-Powered Business Identity and Intelligence Platform for Karnataka, India. This is a hackathon prototype demonstrating a Unified Business Identifier (UBID) system.

---

## WHAT TO BUILD

A multi-view React + Node.js application with mock data that demonstrates the full BizPulse concept end-to-end. Use React (Vite) for frontend and Node.js/Express for backend. Use in-memory mock data — no real database needed.

---

## CORE CONCEPT

BizPulse solves the problem of fragmented business registrations across Karnataka government departments (GST, Udyam, Municipal licences, MSME registry). It assigns a **UBID (Unified Business Identifier)** — like Aadhaar for businesses — and uses AI entity resolution to match businesses across databases.

## TECH STACK

- Frontend: React + Vite, React Router for navigation, Recharts for charts, Tailwind CSS or plain CSS modules
- Backend: Node.js + Express serving mock data as REST API endpoints
- No real database — all mock data in-memory
- Structure: `/client` for React app, `/server` for Express

---

## API ENDPOINTS TO BUILD

- `GET /api/businesses` — all businesses
- `GET /api/businesses/:ubid` — single business profile
- `GET /api/alerts` — active intelligence alerts
- `POST /api/resolve` — mock entity resolution (takes raw records, returns matched UBIDs with scores)
- `GET /api/stats` — platform stats (total businesses, compliance rate, alerts count)
